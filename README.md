ابزار خودکار دانلود ویدیو از YouTube با قابلیت آپلود مستقیم در مخزن GitHub

https://img.shields.io/badge/GitHub%2520Actions-Automated-blue
https://img.shields.io/badge/YouTube-Downloader-red

📖 معرفی پروژه
این پروژه یک ابزار خودکار است که با استفاده از GitHub Actions ویدیوهای مورد نظر شما را از YouTube دانلود کرده و به طور خودکار در مخزن GitHub آپلود می‌کند.

✨ ویژگی‌ها
✅ دانلود خودکار ویدیو از یوتیوب

🎨 کیفیت قابل انتخاب (از 2160p تا 480p و فقط صدا)

📝 دانلود زیرنویس فارسی و انگلیسی

🔐 رمزگذاری فایل‌ها با رمز دلخواه

📦 تقسیم فایل‌های بزرگ (بیشتر از 90MB) به قطعات 70MB

🌐 پروکسی خودکار با Cloudflare WARP برای دسترسی بدون محدودیت

📊 پنل مدیریت آنلاین برای مشاهده و دانلود فایل‌ها

🚀 نحوه استفاده
1️⃣ اجرای دانلود
به بخش Actions در مخزن خود بروید

روی "YouTube Video Downloader Pro" کلیک کنید

روی "Run workflow" کلیک کنید

اطلاعات زیر را وارد کنید:

گزینه	توضیحات	مثال
🔗 لینک ویدیو	لینک ویدیوهای یوتیوب (جدا با کاما یا فاصله)	https://youtu.be/... , https://youtube.com/...
🎬 کیفیت	کیفیت مورد نظر	1080, 720, best, audio
📝 زیرنویس	فعال/غیرفعال کردن دانلود زیرنویس	true / false
🔒 رمز فایل	رمز اختیاری برای فایل‌های فشرده	myPassword123
روی دکمه سبز "Run workflow" کلیک کنید

2️⃣ مشاهده ویدیوهای دانلود شده
بعد از اتمام دانلود، ویدیوها در پوشه videos/ مخزن ذخیره می‌شوند.

برای مشاهده آنلاین و دانلود آسان:

👉 مشاهده صفحه مدیریت فایل‌ها

3️⃣ پاکسازی فایل‌های قدیمی
برای حذف فایل‌های قدیمی و آزادسازی فضا:

به بخش Actions بروید

روی "Cleanup Videos Folder" کلیک کنید

حالت پاکسازی را انتخاب کنید:

all : حذف همه فایل‌ها

by_age : حذف فایل‌های با عمر بیشتر از X دقیقه

by_size : حذف فایل‌های بزرگتر از X مگابایت

keep_latest : نگهداری فقط X فایل آخر

📋 مثال‌های کاربردی
مثال ۱: دانلود یک ویدیو با کیفیت 1080p
text
لینک: https://youtube.com/watch?v=...
کیفیت: 1080
زیرنویس: true
مثال ۲: دانلود چند ویدیو با کیفیت بالا
text
لینک: https://youtu.be/abc123 , https://youtu.be/xyz789
کیفیت: best
زیرنویس: false
رمز: mySecret123
مثال ۳: فقط دانلود صدای یک پلی‌لیست
text
لینک: https://youtube.com/playlist?list=...
کیفیت: audio
زیرنویس: false
🛠️ رفع مشکلات رایج
❌ فایل خیلی بزرگ است و آپلود نمی‌شود
✅ راه حل: پروژه به صورت خودکار فایل‌های بزرگتر از 90MB را به قطعات 70MB تقسیم می‌کند. برای استخراج:

bash
cat file.zip.* > file.zip
unzip file.zip
# یا اگر رمز دارد:
unzip -P password file.zip
❌ ویدیو قابل دانلود نیست
✅ راه حل: به دلیل تحریم‌ها، پروژه از Cloudflare WARP استفاده می‌کند. اگر باز هم مشکل داشتید، لطفاً issue ثبت کنید.

❌ صفحه مدیریت فایل‌ها باز نمی‌شود
✅ راه حل: از لینک زیر استفاده کنید:

text
